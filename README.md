# Sistema de Gestión de Vehículos

Este proyecto es una aplicación de consola desarrollada en Python para gestionar una flota de vehículos aplicando Programación Orientada a Objetos.

## Funcionalidades

- Registro de vehículos organizados en coches y motos.
- Validación de datos de entrada como precios y año de fabricación.
- Control del estado del motor para encender y apagar cada vehículo.
- Simulación de alquiler y devolución de unidades.
- Cálculo de tarifas de alquiler por día para coches y por hora para motos.
- Muestreo de estadísticas generales de la flota registrada.
- Opción para dar de baja y eliminar vehículos del sistema.
